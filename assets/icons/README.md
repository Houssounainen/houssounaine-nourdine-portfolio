# Icônes de réseaux et de contact

Les cinq fichiers SVG proviennent de [Bootstrap Icons 1.13.1](https://github.com/twbs/icons/tree/v1.13.1/icons), sous licence MIT (copie dans `LICENSE`). Les tracés sont conservés ; la couleur d’affichage et les fonds sont définis dans `styles.css`.

- `facebook.svg` : Facebook
- `instagram.svg` : Instagram
- `linkedin.svg` : LinkedIn
- `whatsapp.svg` : WhatsApp
- `envelope.svg` : e-mail

Les logos sont servis depuis le site, sans dépendance à un fournisseur d’icônes externe. Le nom du réseau est conservé dans le texte visible ou le nom accessible du lien.
